# qresearch

**Количественная аналитика финансовых рынков для всех.**

Библиотека `qresearch` превращает многостраничные ноутбуки по квант-анализу в две строки кода. Она создана для людей без навыков программирования: передайте тикер, получите готовый отчёт со статистиками доходностей, риск-метриками, диагностикой модели, Монте-Карло и графиками.

```python
import qresearch as qr

qr.report(["RUGBITR5+", "RUSFARIND"])   # полный отчёт: 9 таблиц + графики
```

Или еще проще, если не хочется ничего устанавливать локально: [examples/quickstart.py](examples/quickstart.py) открывается в Google Colab.

## Установка

```bash
pip install qresearch
```

Зависимости ставятся автоматически: `pandas`, `numpy`, `scipy`, `matplotlib`, `yfinance`.

## Что умеет

- **Данные**: акции и индексы МосБиржи (MOEX ISS API), мировые активы через Yahoo Finance, ваши CSV/Excel файлы. Источник выбирается автоматически по тикеру.
- **Статистика**: средняя, медиана, СКО, коэффициент вариации, эксцесс и асимметрия, CAGR, годовые доходности, волатильность, Шарп, Сортино, Калмар.
- **Риск**: VaR (исторический, параметрический) и CVaR, максимальная и текущая просадки с датами пика, дна и восстановления.
- **Диагностика**: тесты нормальности (Жарка-Бера, Шапиро-Уилка), проверка кластеризации волатильности (Ljung-Box), стационарность (тест Дики-Фуллера).
- **Монте-Карло**: тысячи симуляций тремя методами: iid-бутстреп, блочный бутстреп, параметрический; P(убыток), доверительные интервалы. Один и тот же seed дает одинаковые результаты.
- **Портфели**: доходность и волатильность с учетом корреляций, вклад каждого актива в риск, веса минимальной дисперсии.
- **Графики**: рост с базой 100 в лог-шкале, гистограмма доходностей с наложенной нормалью и t-распределением, QQ-график, просадки, скользящая волатильность, годовые столбики.

## Быстрый старт

### Одна функция, которая делает всё

```python
import qresearch as qr

result = qr.report(["RUGBITR5+", "RUSFARIND"], n_sims=10000)
# печатает таблицы отчёта, показывает графики,
# возвращает словарь с датафреймами для дальнейшей работы
```

### Главные цифры без лишнего

```python
qr.quick(["SBER", "GAZP", "RUGBITR5+"])
```

### Портфель в одну строку

```python
p = qr.portfolio(["SBER", "GAZP", "RUGBITR5+"], weights=[0.5, 0.3, 0.2])
p.summary()               # доходность и риск портфеля
p.correlation()           # матрица корреляций
p.risk_contribution()     # вклад активов в риск, %
p.min_variance()          # веса минимальной дисперсии
```

### Отдельные метрики

```python
qr.stats_table(["SBER", "GAZP"])    # таблица всех статистик
qr.annual_table("RUGBITR5+")        # доходности по годам
qr.diagnostics("RUGBITR5+")         # нормальность, кластеризация, ADF
qr.monte_carlo_table("RUGBITR5+")   # итоги Монте-Карло
qr.var("SBER", level=95)            # VaR
qr.cvar("SBER", level=99)           # CVaR
qr.drawdown_info("SBER")            # просадка + даты пика и дна
```

### Графики

```python
qr.plot_growth(["SBER", "GAZP"])   # база 100, лог-шкала
qr.plot_histogram("SBER")          # гистограмма + нормаль + t
qr.plot_qq("SBER")                 # QQ-график
qr.plot_drawdown("SBER")           # просадки
qr.plot_rolling_vol("SBER")        # скользящая волатильность
qr.plot_annual("SBER")             # годовые столбики
```

### Свои данные из Excel или CSV

```python
a = qr.load_file("цены.xlsx")                     # колонки угадываются сами
b = qr.load_file("цены.csv", date_col="Дата",
                 price_col="Цена закрытия")        # или укажите явно
qr.quick([a, b])
```

### Индексы МосБиржи по человекочитаемым названиям

```python
qr.quick(["ОФЗ > 5 лет", "MOEX Blue Chips"])   # пресеты внутри библиотеки
```

### Загрузка без анализа (кэшируется в памяти)

```python
a = qr.load("SBER")        # акция МосБиржи
b = qr.load("AAPL")        # Yahoo Finance
c = qr.load("RUGBITR5+")   # индекс ОФЗ
d = qr.load_moex("SBER", "2023-01-01", "2023-12-31")   # явный период
```

### Шпаргалка

```python
qr.help()   # печатает краткую справку по всем функциям
```

## Как это работает без программирования

1. Каждая функция принимает либо тикер (строку), либо список тикеров, либо уже загруженный объект.
2. Данные скачиваются и кэшируются автоматически; повторные вызовы мгновенны.
3. Все таблицы подписаны по-русски и готовы для вставки в отчёт или презентацию.
4. Всё считается на `numpy`/`scipy`: векторизация без циклов, отчёт по 20 годам истории занимает секунды.

## Структура проекта

```
src/qresearch/
    _core.py        # класс Asset, нормализация данных
    data.py         # MOEX ISS, Yahoo Finance, CSV/Excel
    stats.py        # статистики доходностей
    risk.py         # VaR, CVaR, просадки
    diagnostics.py  # тесты нормальности, кластеризации, стационарности
    montecarlo.py   # Монте-Карло: бутстреп и параметрический
    portfolio.py    # портфельная аналитика
    plots.py        # графики matplotlib
    report.py       # quick и report: отчёт целиком
tests/              # 12 тестов на синтетических данных (без интернета)
examples/quickstart.py
```
