# qresearch

**Количественная аналитика финансовых рынков для всех.**

`qresearch` превращает многостраничный ноутбук по квант-анализу в две строки кода: передайте тикер МосБиржи или свой CSV-файл и получите статистики доходностей, риск-метрики, диагностику модели, Монте-Карло, портфельную аналитику и графики.

```python
import qresearch as qr

qr.report(["SBER", "GAZP"])   # полный отчёт: статистики, диагностика, Монте-Карло, портфель, графики
```

## Установка

```bash
pip install qresearch
```

Зависимости ставятся автоматически: `pandas`, `numpy`, `scipy`, `matplotlib`. Интернет нужен только при загрузке данных с МосБиржи; весь анализ и работа с локальными файлами идут офлайн.

## Источники данных

- **МосБиржа (публичный ISS API)**: акции (`SBER`, `GAZP`, `LKOH`, ...) и индексы (`IMOEX`, `RTSI`, `MOEXBC`). Доска торгов определяется по тикеру автоматически.
- **Локальные файлы**: CSV и Excel через `load_file`; разделитель и кодировка CSV подбираются автоматически, колонки даты и цены распознаются по типичным названиям (в том числе русским).
- **Псевдонимы**: вместо тикеров индексов можно передавать названия из `INDEX_PRESETS`, например `"Индекс МосБиржи"`.

## Быстрый старт

### Одна функция, которая делает всё

```python
import qresearch as qr

result = qr.report(["SBER", "GAZP"], n_sims=10000)
# печатает таблицы отчёта, показывает графики,
# возвращает словарь с DataFrame для дальнейшей работы
```

### Ключевые метрики без лишнего

```python
qr.quick(["SBER", "GAZP", "IMOEX"])   # таблица-картинка matplotlib
qr.quick(["SBER", "GAZP"], plot=False)  # то же текстом, как раньше
```

### Одно число одной командой

Каждая метрика живёт отдельной функцией: ничего не печатает, просто возвращает число
(доля единицы, например `0.0834` = 8.34%):

```python
qr.cagr("SBER")           # годовая доходность (геометрическая)
qr.volatility("SBER")     # годовая волатильность
qr.sharpe("SBER")         # Шарп
qr.sortino("SBER")        # Сортино
qr.calmar("SBER")         # Калмара
qr.max_drawdown("SBER")   # максимальная просадка (отрицательное число)
qr.var("SBER", 95)        # VaR 95%
qr.cvar("SBER", 99)       # CVaR 99%
qr.annual_returns("SBER") # Series доходностей по календарным годам, %
```

### Только Монте-Карло

```python
sims = qr.monte_carlo("SBER", n_sims=10000)   # словарь: метод -> массив симуляций
qr.monte_carlo_table("SBER", n_sims=10000)    # сводная таблица
qr.plot_monte_carlo("SBER")                    # гистограмма с P5/P50/P95
```

### Портфель в одну строку

```python
p = qr.portfolio(["SBER", "GAZP", "LKOH"], weights=[0.5, 0.3, 0.2])
p.summary()               # доходность и риск портфеля
p.correlation()           # матрица корреляций
p.risk_contribution()     # вклад активов в риск, %
p.min_variance()          # веса минимальной дисперсии
```

### Отдельные метрики

```python
qr.stats_table(["SBER", "GAZP"])    # все описательные статистики
qr.annual_table("IMOEX")            # доходности по годам
qr.diagnostics("SBER")              # нормальность, кластеризация, стационарность
qr.monte_carlo_table("SBER")        # итоги Монте-Карло
qr.var("SBER", level=95)            # VaR
qr.cvar("SBER", level=99)           # CVaR
qr.drawdown_info("SBER")            # просадка + даты пика и дна
```

### Графики

```python
qr.plot_growth(["SBER", "GAZP"])   # база 100, лог-шкала
qr.plot_histogram("SBER")          # гистограмма + нормаль + t
qr.plot_qq("SBER")                 # QQ-график
qr.plot_drawdown("SBER")           # просадки
qr.plot_rolling_vol("SBER")        # скользящая волатильность
qr.plot_annual("SBER")             # годовые столбики
qr.plot_monte_carlo("SBER")        # Монте-Карло: гистограмма симуляций года
qr.plot_table(qr.stats_table("SBER"))  # любой DataFrame - таблица-картинка
```

### Свои данные из Excel или CSV

```python
a = qr.load_file("цены.xlsx")                     # колонки угадываются сами
b = qr.load_file("цены.csv", date_col="Дата",
                 price_col="Цена закрытия")        # или укажите явно
qr.quick([a, b])
```

### Загрузка без анализа (кэшируется в памяти)

```python
a = qr.load("SBER")                                # акция МосБиржи
b = qr.load("IMOEX")                               # индекс МосБиржи
c = qr.load_moex("SBER", "2023-01-01", "2023-12-31")   # явный период
```

### Шпаргалка

```python
qr.help()   # печатает краткую справку по всем функциям
```

## Справочник функций

Во все функции анализа вместо тикера можно передавать уже загруженный `Asset`, `pd.Series`, `pd.DataFrame` или `dict` с колонками даты и цены.

### Данные

- `load(ticker, start=None, end=None, name=None) -> Asset` - загружает историю цен по тикеру с МосБиржи. Понимает псевдонимы из `INDEX_PRESETS`, кэширует результат: повторный вызов по тому же тикеру и периоду не ходит в сеть.
- `load_moex(ticker, start=None, end=None, board=None, name=None) -> Asset` - то же, но явно с ISS API МосБиржи: можно задать границы периода (`"ГГГГ-ММ-ДД"`) и код доски торгов; по умолчанию доска определяется автоматически через `/iss/securities`. История выкачивается постранично, для акций по умолчанию с 2010-01-01.
- `load_file(path, date_col=None, price_col=None, name=None) -> Asset` - читает CSV или Excel. Кодировка (`utf-8`, `cp1251`) и разделитель (`,`, `;`, таб) подбираются перебором. Если колонки названы нестандартно, укажите `date_col` и `price_col` вместе.
- `Asset(data, name=None)` - нормализованный временной ряд цен: `.prices` (отсортированные цены), `.returns` (дневные простые доходности), `.dates`, `.opy` (фактическое число наблюдений в году по длине истории).
- `INDEX_PRESETS` - словарь человекочитаемых псевдонимов индексов.
- `to_asset(x)`, `ensure_list(x)` - служебные: превращают любой вход в `Asset` и оборачивают одиночный объект в список.

### Описательные статистики

- `daily_stats(x) -> pd.Series` - полный набор метик дневных доходностей: период, число наблюдений, средняя годовая (арифметическая), CAGR (геометрическая), годовая волатильность, минимальный и максимальный день с датами, асимметрия, избыточный эксцесс, доля отрицательных дней, исторические VaR и CVaR на 95% и 99%, максимальная скользящая волатильность (63 дня), максимальная просадка с датой дна и датой восстановления, Шарп.
- `stats_table(tickers) -> pd.DataFrame` - то же для нескольких активов, активы в колонках.
- `annual_returns(x) -> pd.Series` - доходность каждого календарного года, %.
- `annual_table(tickers, mark_incomplete=True) -> pd.DataFrame` - годовые доходности нескольких активов рядом; неполный последний год помечается `*` (`mark_incomplete=False` - числовой индекс годов).
- `annual_stats(x) -> pd.Series` - статистики годовых доходностей полных лет: число лет, средняя, СКО, минимум, квартили 25/50/75%, максимум, доля положительных лет и число убыточных. Неполный последний год отбрасывается, как и первый год, если данных с его второй половины.
- `full_stats(x) -> pd.Series` - полная статистика дневных доходностей одним списком: период и наблюдения, средняя и CAGR, волатильность, экстремумы с датами отдельными строками, асимметрия и эксцесс, доля отрицательных дней, исторические и параметрические VaR/CVaR, превышения VaR (факт/ожидалось), максимальная скользящая волатильность, просадка с датами пика, дна и восстановления, Шарп, p-value Жарка-Бера, ADF и Льюнг-Бокса по доходностям и их квадратам.
- `full_stats_table(tickers) -> pd.DataFrame` - то же для нескольких активов, активы в колонках: `qr.plot_table(qr.full_stats_table(["SBER", "GAZP"]))`.
- `compare_annual(x, y) -> (pd.DataFrame, float)` - годовые доходности двух инструментов на общем периоде (`*` - неполный год) и корреляция их дневных доходностей: `df, corr = qr.compare_annual("SBER", "GAZP")`.
- `sharpe_vs(x, benchmark) -> float` - Шарп актива относительно другого инструмента (например, индекса или денежного рынка) на общем периоде: избыток средней доходности, делённый на волатильность актива.
- `implied_rate(x) -> pd.Series` - годовая ставка, %, восстановленная из капитализированного индекса: доходность наблюдения аннуализируется по фактическому числу календарных дней до следующего наблюдения.
- `cagr(x) -> float` - годовой темп роста, доля единицы.
- `volatility(x) -> float` - годовая волатильность дневных доходностей, доля единицы.
- `sharpe(x) -> float` - коэффициент Шарпа (безрисковая ставка 0).
- `sortino(x) -> float` - коэффициент Сортино (в знаменателе СКО только убыточных дней).
- `calmar(x) -> float` - CAGR к модулю максимальной просадки.

### Риск

- `var(x, level=95, method="hist") -> float` - Value at Risk дневных доходностей, доля единицы (отрицательное число). `method="hist"` - исторический перцентиль; `method="parametric"` - нормальное распределение N(mu, sigma).
- `cvar(x, level=95, method="hist") -> float` - Expected Shortfall: средний убыток за уровнем VaR.
- `drawdown(x) -> pd.Series` - текущая просадка от исторического пика (всегда <= 0).
- `max_drawdown(x) -> float` - максимальная просадка за всю историю.
- `drawdown_info(x) -> dict` - максимальная просадка, %, с датами пика, дна и восстановления ("-", если пик ещё не восстановлен).
- `rolling_vol(x, window=63) -> pd.Series` - скользящая годовая волатильность, % (63 дня - квартал).
- `var_backtest(x, level=95, method="parametric") -> pd.Series` - бэктест VaR: сколько раз дневной убыток превысил VaR, сравнение с ожидаемым числом превышений (`n * (1 - уровень/100)`). Факт сильно больше ожидаемого - модель недооценивает риск.

### Диагностика модели

- `normality_tests(x) -> pd.Series` - Жарк-Бера и Шапиро-Уилка (Шапиро берёт первые 5000 наблюдений из-за ограничения теста) и итоговый вывод при уровне значимости 5%.
- `autocorrelation_test(x, lags=(5, 20)) -> pd.Series` - Льюнг-Бокс по самим доходностям: заметная автокорреляция означает, что «вчерашний день помогает предсказать сегодняшний» и наблюдения зависимы.
- `volatility_clustering_test(x, lags=(5, 20)) -> pd.Series` - Льюнг-Бокс по квадратам доходностей: проверяет, ходят ли большие движения группами (кластеризация волатильности). Оба теста через statsmodels, с p-value по каждому лагу.
- `stationarity_test(x) -> pd.Series` - тест Дики-Фуллера (ADF, statsmodels, лаг подбирается автоматически по AIC): t-статистика, p-value и критическое значение 5%. p-value < 0.05 - ряд стационарен, случайное блуждание отвергается.
- `diagnostics(x, print_=False) -> dict` - все три теста сразу; при `print_=True` печатает их.

### Монте-Карло

- `monte_carlo(x, days=None, n_sims=20000, seed=42, block=21) -> dict` - моделирует годовую доходность тремя способами: (1) iid-бутстреп - дни берутся из истории независимо с возвращением; (2) блочный бутстреп - куски по `block` дней подряд, сохраняет кластеризацию волатильности; (3) параметрический - дни из нормального N(mu, sigma). `days=None` (по умолчанию) - фактическое число наблюдений в году по истории актива (например, 251 у индексов МосБиржи), а не круглые 252. Возвращает словарь "метод -> массив годовых доходностей" длиной `n_sims`.
- `mc_summary(sims) -> pd.Series` - P(убыток), средняя, СКО и перцентили 1/5/50/95/99, %.
- `monte_carlo_table(x, days=None, n_sims=20000, seed=42, block=21) -> pd.DataFrame` - сводная таблица по всем трём методам.

Один и тот же `seed` даёт одинаковые результаты цифра в цифру.

### Портфели

- `portfolio(assets, weights=None) -> Portfolio` - создаёт портфель по общим датам активов. Веса по умолчанию равные; отрицательные веса запрещены, веса нормируются к сумме 1.
- `Portfolio.summary() -> pd.Series` - CAGR, годовая волатильность и Шарп портфеля.
- `Portfolio.correlation() -> pd.DataFrame` - матрица корреляций дневных доходностей.
- `Portfolio.risk_contribution() -> pd.Series` - вклад каждого актива в дисперсию портфеля, % (сумма 100).
- `Portfolio.min_variance() -> pd.Series` - аналитические веса минимальной дисперсии; шорты допускаются, сумма весов 1.
- `Portfolio.portfolio_returns() -> np.ndarray` - дневные доходности портфеля на общих датах.

### Графики

Каждая функция рисует готовый рисунок в едином стиле (крупные фигуры, сетка 0.35, палитра `#1f77b4`/`#2ca02c`/`#d62728`). Однопанельные графики возвращают оси matplotlib, многопанельные - фигуру (на них можно дорисовывать поверх).

Параметр `save` есть у каждого графика: `save=True` - показать и сохранить PNG (dpi=150) в папку `qr_plots`, `save="папка"` - в указанную папку, `save="файл.png"` - по точному пути. `save=None` - только показать (по умолчанию).

- `plot_growth(x, log=True, save=None)` - накопленная динамика с базой 100; лог-шкала по умолчанию показывает процентные темпы роста, в легенде - дата старта каждого актива.
- `plot_returns(x, save=None)` - дневные доходности во времени, %, по панели на актив; по форме линии видна кластеризация волатильности.
- `plot_histogram(x, bins=120, save=None)` - гистограмма дневных доходностей, %, с наложенными нормалью (пунктир) и подобранным t-распределением; в заголовке - число дней и сколько точек попало «вне оси» (ось обрезана по перцентилям 0.1-99.9).
- `plot_qq(x, save=None)` - QQ-график как в оригинальной работе: по обеим осям проценты (выборочные квантили против квантилей нормали, подогнанной к ряду), одинаковые пределы осей, пунктирная диагональ y = x из угла в угол; S-образные концы = «тяжёлые хвосты», отклонение читается прямо в процентах. Панель ~6.5x5.5; для списка активов - по панели на актив. Подписи осей - дословно как в работе.
- `plot_drawdown(x, save=None)` - просадки от исторических пиков: серая линия с заливкой; в заголовке максимальная просадка и дата дна.
- `plot_rolling_vol(x, window=63, save=None)` - скользящая годовая волатильность, % (63 дня - квартал).
- `plot_annual(x, save=None)` - две панели: годовые доходности столбиками по годам (`*` - неполный год) и распределение годовых доходностей полных лет. Возвращает фигуру.
- `plot_monte_carlo(x, n_sims=20000, days=None, seed=42, block=21, bins=60, save=None)` - смоделированные распределения годовой доходности: iid- и блочный бутстреп гистограммами (блочный даёт более тяжёлые хвосты), параметрический метод - красной кривой нормальной плотности; по панели на актив. Возвращает фигуру.
- `plot_table(data, title="", fontsize=10, save=None)` - рисует любой DataFrame или Series таблицей-картинкой matplotlib; NaN показывается прочерком. Удобно для отчётов и скриншотов.
- `plot_all(x, save=None)` - все основные графики по каждому активу: рост, дневные доходности, гистограмма, QQ, просадки, скользящая волатильность, годовые.

### Отчёты

- `quick(x, plot=True) -> pd.DataFrame` - ключевые метрики (период, наблюдений, CAGR, волатильность, Шарп, максимальная просадка). По умолчанию таблица рисуется картинкой matplotlib; `plot=False` - прежний текстовый вывод. Возвращает DataFrame в любом случае.
- `report(x, days=None, n_sims=20000, seed=42, block=21, show_plots=True) -> dict` - полный отчёт: печатает описательные статистики, годовые доходности и их статистики, диагностику, Монте-Карло (по каждому активу), портфельный блок (если активов больше одного) и показывает графики. Возвращает словарь с ключами `stats`, `annual`, `diagnostics`, `monte_carlo`, `portfolio`. `days=None` - моделировать год с фактическим числом торговых дней актива.
- `help()` - печатает шпаргалку по библиотеке.

## Как это работает без программирования

1. Каждая функция принимает тикер (строку), список тикеров, `Asset`, Series/DataFrame или dict с колонками даты и цены.
2. Данные скачиваются и кэшируются автоматически; повторные вызовы мгновенны.
3. Все таблицы подписаны по-русски и готовы для вставки в отчёт или презентацию.
4. Годичные коэффициенты масштабируются через фактическое число наблюдений в году вашей истории, а не через фиксированные 252 дня.
5. Всё считается на `numpy`/`scipy` векторно: полный отчёт по 15 годам истории занимает секунды.

## Структура проекта

```
src/qresearch/
    _core.py        # класс Asset, нормализация и очистка данных
    data.py         # МосБиржа (ISS API) и локальные CSV/Excel
    stats.py        # описательные и годовые статистики
    risk.py         # VaR, CVaR, просадки, скользящая волатильность
    diagnostics.py  # нормальность, кластеризация, стационарность
    montecarlo.py   # бутстреп и параметрическая симуляция
    portfolio.py    # портфельная аналитика
    plots.py        # графики matplotlib
    report.py       # отчёты целиком: quick и report
tests/              # тесты на синтетических данных (интернет не нужен)
examples/quickstart.py
```

## CI и публикация

Тесты гоняются на Python 3.9-3.13 при каждом пуше: [`.github/workflows/tests.yml`](.github/workflows/tests.yml). Публикация на PyPI настроена через Trusted Publishing (без токенов): создание GitHub-релиза автоматически собирает пакет и публикует его: [`.github/workflows/publish.yml`](.github/workflows/publish.yml).
