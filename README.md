# qresearch

**Количественная аналитика финансовых рынков для всех.**

`qresearch` превращает многостраничный ноутбук по квант-анализу в две строки кода: передайте тикер МосБиржи или свой CSV-файл и получите статистики доходностей, риск-метрики, диагностику модели, Монте-Карло, портфельную аналитику и графики.

```python
import qresearch as qr

qr.report(["SBER", "GAZP"])   # полный отчёт: статистики, диагностика, Монте-Карло, портфель, графики
```

## Установка

```bash
pip install qresearch
```

Зависимости ставятся автоматически: `pandas`, `numpy`, `scipy`, `matplotlib`. Интернет нужен только при загрузке данных с МосБиржи; весь анализ и работа с локальными файлами идут офлайн.

## Источники данных

- **МосБиржа (публичный ISS API)**: акции (`SBER`, `GAZP`, `LKOH`, ...) и индексы (`IMOEX`, `RTSI`, `MOEXBC`). Доска торгов определяется по тикеру автоматически.
- **Локальные файлы**: CSV и Excel через `load_file`; разделитель и кодировка CSV подбираются автоматически, колонки даты и цены распознаются по типичным названиям (в том числе русским).
- **Псевдонимы**: вместо тикеров индексов можно передавать названия из `INDEX_PRESETS`, например `"Индекс МосБиржи"`.

## Быстрый старт

### Одна функция, которая делает всё

```python
import qresearch as qr

result = qr.report(["SBER", "GAZP"], n_sims=10000)
# печатает таблицы отчёта, показывает графики,
# возвращает словарь с DataFrame для дальнейшей работы
```

### Ключевые метрики без лишнего

```python
qr.quick(["SBER", "GAZP", "IMOEX"])
```

### Портфель в одну строку

```python
p = qr.portfolio(["SBER", "GAZP", "LKOH"], weights=[0.5, 0.3, 0.2])
p.summary()               # доходность и риск портфеля
p.correlation()           # матрица корреляций
p.risk_contribution()     # вклад активов в риск, %
p.min_variance()          # веса минимальной дисперсии
```

### Отдельные метрики

```python
qr.stats_table(["SBER", "GAZP"])    # все описательные статистики
qr.annual_table("IMOEX")            # доходности по годам
qr.diagnostics("SBER")              # нормальность, кластеризация, стационарность
qr.monte_carlo_table("SBER")        # итоги Монте-Карло
qr.var("SBER", level=95)            # VaR
qr.cvar("SBER", level=99)           # CVaR
qr.drawdown_info("SBER")            # просадка + даты пика и дна
```

### Графики

```python
qr.plot_growth(["SBER", "GAZP"])   # база 100, лог-шкала
qr.plot_histogram("SBER")          # гистограмма + нормаль + t
qr.plot_qq("SBER")                 # QQ-график
qr.plot_drawdown("SBER")           # просадки
qr.plot_rolling_vol("SBER")        # скользящая волатильность
qr.plot_annual("SBER")             # годовые столбики
```

### Свои данные из Excel или CSV

```python
a = qr.load_file("цены.xlsx")                     # колонки угадываются сами
b = qr.load_file("цены.csv", date_col="Дата",
                 price_col="Цена закрытия")        # или укажите явно
qr.quick([a, b])
```

### Загрузка без анализа (кэшируется в памяти)

```python
a = qr.load("SBER")                                # акция МосБиржи
b = qr.load("IMOEX")                               # индекс МосБиржи
c = qr.load_moex("SBER", "2023-01-01", "2023-12-31")   # явный период
```

### Шпаргалка

```python
qr.help()   # печатает краткую справку по всем функциям
```

## Справочник функций

Во все функции анализа вместо тикера можно передавать уже загруженный `Asset`, `pd.Series`, `pd.DataFrame` или `dict` с колонками даты и цены.

### Данные

- `load(ticker, start=None, end=None, name=None) -> Asset` - загружает историю цен по тикеру с МосБиржи. Понимает псевдонимы из `INDEX_PRESETS`, кэширует результат: повторный вызов по тому же тикеру и периоду не ходит в сеть.
- `load_moex(ticker, start=None, end=None, board=None, name=None) -> Asset` - то же, но явно с ISS API МосБиржи: можно задать границы периода (`"ГГГГ-ММ-ДД"`) и код доски торгов; по умолчанию доска определяется автоматически через `/iss/securities`. История выкачивается постранично, для акций по умолчанию с 2010-01-01.
- `load_file(path, date_col=None, price_col=None, name=None) -> Asset` - читает CSV или Excel. Кодировка (`utf-8`, `cp1251`) и разделитель (`,`, `;`, таб) подбираются перебором. Если колонки названы нестандартно, укажите `date_col` и `price_col` вместе.
- `Asset(data, name=None)` - нормализованный временной ряд цен: `.prices` (отсортированные цены), `.returns` (дневные простые доходности), `.dates`, `.opy` (фактическое число наблюдений в году по длине истории).
- `INDEX_PRESETS` - словарь человекочитаемых псевдонимов индексов.
- `to_asset(x)`, `ensure_list(x)` - служебные: превращают любой вход в `Asset` и оборачивают одиночный объект в список.

### Описательные статистики

- `daily_stats(x) -> pd.Series` - полный набор метик дневных доходностей: период, число наблюдений, средняя годовая (арифметическая), CAGR (геометрическая), годовая волатильность, минимальный и максимальный день с датами, асимметрия, избыточный эксцесс, доля отрицательных дней, исторические VaR и CVaR на 95% и 99%, максимальная скользящая волатильность (63 дня), максимальная просадка с датой дна и датой восстановления, Шарп.
- `stats_table(tickers) -> pd.DataFrame` - то же для нескольких активов, активы в колонках.
- `annual_returns(x) -> pd.Series` - доходность каждого календарного года, %.
- `annual_table(tickers) -> pd.DataFrame` - годовые доходности нескольких активов рядом.
- `annual_stats(x) -> pd.Series` - статистики по полным годам: число лет, средняя, СКО, число убыточных, лучшая и худшая доходность. Неполный последний год отбрасывается, как и первый год, если данных с его второй половины.
- `cagr(x) -> float` - годовой темп роста, доля единицы.
- `volatility(x) -> float` - годовая волатильность дневных доходностей, доля единицы.
- `sharpe(x) -> float` - коэффициент Шарпа (безрисковая ставка 0).
- `sortino(x) -> float` - коэффициент Сортино (в знаменателе СКО только убыточных дней).
- `calmar(x) -> float` - CAGR к модулю максимальной просадки.

### Риск

- `var(x, level=95, method="hist") -> float` - Value at Risk дневных доходностей, доля единицы (отрицательное число). `method="hist"` - исторический перцентиль; `method="parametric"` - нормальное распределение N(mu, sigma).
- `cvar(x, level=95, method="hist") -> float` - Expected Shortfall: средний убыток за уровнем VaR.
- `drawdown(x) -> pd.Series` - текущая просадка от исторического пика (всегда <= 0).
- `max_drawdown(x) -> float` - максимальная просадка за всю историю.
- `drawdown_info(x) -> dict` - максимальная просадка, %, с датами пика, дна и восстановления ("-", если пик ещё не восстановлен).
- `rolling_vol(x, window=63) -> pd.Series` - скользящая годовая волатильность, % (63 дня - квартал).

### Диагностика модели

- `normality_tests(x) -> pd.Series` - Жарк-Бера и Шапиро-Уилка (Шапиро берёт первые 5000 наблюдений из-за ограничения теста) и итоговый вывод при уровне значимости 5%.
- `volatility_clustering_test(x, lags=(1, 5, 10, 20)) -> pd.Series` - Ljung-Box по квадратам доходностей: проверяет, ходят ли большие движения группами (автокорреляция волатильности).
- `stationarity_test(x) -> pd.Series` - упрощённый ADF: регрессия доходности на свою лаговую величину с константой, H0 - случайное блуждание; t-статистика сравнивается с критическим значением 5%.
- `diagnostics(x, print_=False) -> dict` - все три теста сразу; при `print_=True` печатает их.

### Монте-Карло

- `monte_carlo(x, days=252, n_sims=20000, seed=42, block=21) -> dict` - моделирует годовую доходность тремя способами: (1) iid-бутстреп - дни берутся из истории независимо с возвращением; (2) блочный бутстреп - куски по `block` дней подряд, сохраняет кластеризацию волатильности; (3) параметрический - дни из нормального N(mu, sigma). Возвращает словарь "метод -> массив годовых доходностей" длиной `n_sims`.
- `mc_summary(sims) -> pd.Series` - P(убыток), средняя, СКО и перцентили 1/5/50/95/99, %.
- `monte_carlo_table(x, days=252, n_sims=20000, seed=42, block=21) -> pd.DataFrame` - сводная таблица по всем трём методам.

Один и тот же `seed` даёт одинаковые результаты цифра в цифру.

### Портфели

- `portfolio(assets, weights=None) -> Portfolio` - создаёт портфель по общим датам активов. Веса по умолчанию равные; отрицательные веса запрещены, веса нормируются к сумме 1.
- `Portfolio.summary() -> pd.Series` - CAGR, годовая волатильность и Шарп портфеля.
- `Portfolio.correlation() -> pd.DataFrame` - матрица корреляций дневных доходностей.
- `Portfolio.risk_contribution() -> pd.Series` - вклад каждого актива в дисперсию портфеля, % (сумма 100).
- `Portfolio.min_variance() -> pd.Series` - аналитические веса минимальной дисперсии; шорты допускаются, сумма весов 1.
- `Portfolio.portfolio_returns() -> np.ndarray` - дневные доходности портфеля на общих датах.

### Графики

Каждая функция рисует готовый рисунок и возвращает оси matplotlib (можно дорисовывать поверх).

- `plot_growth(x, log=True)` - рост с базой 100; лог-шкала по умолчанию, чтобы визуально сравнивать темпы роста.
- `plot_returns(x)` - дневные доходности во времени, %.
- `plot_histogram(x, bins=80)` - гистограмма доходностей с наложенными нормалью и подобранным t-распределением: видно, насколько реальный хвост толще нормального.
- `plot_qq(x)` - QQ-график против нормального распределения.
- `plot_drawdown(x)` - просадки от исторических пиков.
- `plot_rolling_vol(x, window=63)` - скользящая годовая волатильность.
- `plot_annual(x)` - годовые доходности столбиками.
- `plot_all(x)` - все основные графики по каждому активу.

### Отчёты

- `quick(x) -> pd.DataFrame` - печатает и возвращает таблицу ключевых метрик: период, наблюдений, CAGR, волатильность, Шарп, максимальная просадка.
- `report(x, days=252, n_sims=20000, seed=42, block=21, show_plots=True) -> dict` - полный отчёт: печатает описательные статистики, годовые доходности и их статистики, диагностику, Монте-Карло (по каждому активу), портфельный блок (если активов больше одного) и показывает графики. Возвращает словарь с ключами `stats`, `annual`, `diagnostics`, `monte_carlo`, `portfolio`.
- `help()` - печатает шпаргалку по библиотеке.

## Как это работает без программирования

1. Каждая функция принимает тикер (строку), список тикеров, `Asset`, Series/DataFrame или dict с колонками даты и цены.
2. Данные скачиваются и кэшируются автоматически; повторные вызовы мгновенны.
3. Все таблицы подписаны по-русски и готовы для вставки в отчёт или презентацию.
4. Годичные коэффициенты масштабируются через фактическое число наблюдений в году вашей истории, а не через фиксированные 252 дня.
5. Всё считается на `numpy`/`scipy` векторно: полный отчёт по 15 годам истории занимает секунды.

## Структура проекта

```
src/qresearch/
    _core.py        # класс Asset, нормализация и очистка данных
    data.py         # МосБиржа (ISS API) и локальные CSV/Excel
    stats.py        # описательные и годовые статистики
    risk.py         # VaR, CVaR, просадки, скользящая волатильность
    diagnostics.py  # нормальность, кластеризация, стационарность
    montecarlo.py   # бутстреп и параметрическая симуляция
    portfolio.py    # портфельная аналитика
    plots.py        # графики matplotlib
    report.py       # отчёты целиком: quick и report
tests/              # тесты на синтетических данных (интернет не нужен)
examples/quickstart.py
```
