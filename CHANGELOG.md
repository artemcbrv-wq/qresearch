# Changelog

## 0.1.0 - 2026-11-06

Первый релиз `qresearch`.

- Данные: акции и индексы МосБиржи (MOEX ISS API), Yahoo Finance, CSV/Excel файлы; источник выбирается автоматически по тикеру; кэш в памяти.
- Статистики: полный набор таблицы 7 отчёта (средняя, CAGR, волатильность, асимметрия, эксцесс, VaR/CVaR, просадки, Шарп).
- Годовые доходности: таблица 8 и статистики по полным годам.
- Диагностика: Жарк-Бера, Шапиро-Уилка, Ljung-Box по квадратам доходностей, ADF-тест.
- Монте-Карло: iid-бутстреп, блочный бутстреп, параметрическая нормальная симуляция (таблица 9), воспроизводимость через seed.
- Портфели: доходность и волатильность с учётом корреляций, вклад в риск, веса минимальной дисперсии.
- Графики: рост с базой 100, гистограмма с нормалью и t-распределением, QQ-график, просадки, скользящая волатильность, годовые столбики.
- Отчёты одной командой: `quick` и `report`.
- Тесты на синтетических данных, CI на Python 3.9-3.13, автопубликация на PyPI через Trusted Publishing.
